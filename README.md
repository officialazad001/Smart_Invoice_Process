# 🛡️ SmartInvoice Fraud Agent
> **AI & RPA Powered Invoice Validation & Fraud Detection**  
> *Built on UiPath REFramework | Hackathon Submission*

---

## 📌 About The Project
SmartInvoice Fraud Agent ek automated solution hai jo manual invoice processing ke errors, delays aur payment frauds ko khatam karta hai[cite: 10]. Yeh system invoices ko automatically read karta hai, validation checks run karta hai, aur real-time fraud detect karta hai[cite: 10].

---

## ⚡ Key Features
* **90% Faster Processing:** Invoices ko seconds me process karta hai[cite: 10].
* **Multi-Layer Fraud Detection Engine:**
  * **Layer 1:** Duplicate invoices aur hash checks identify karta hai[cite: 10].
  * **Layer 2:** Vendor name, Tax ID aur IBAN verify karta hai[cite: 10].
  * **Layer 3:** Tax totals, mathematical errors aur line-item anomalies check karta hai[cite: 10].
* **Human-In-The-Loop (HITL):** Suspicious invoices ko review ke liye human manager ko escalate karta hai[cite: 10].
* **Enterprise Security:** Credentials ko secure vault me manage karta hai aur complete audit log maintain karta hai[cite: 10].

---

## 🏗️ Technical Architecture
* **Framework:** UiPath Robotic Enterprise Framework (REFramework)[cite: 10]
* **Design Pattern:** Decoupled Dispatcher & Performer Model[cite: 10]
* **Integration:** Email Automation (IMAP), Orchestrator Queues, Excel Reporting, Document Understanding[cite: 10]

---

## 🛠️ How To Run
1. Repo ko local machine par clone karein.
2. Dependencies ko UiPath Studio me restore karein.
3. UiPath Orchestrator me Assets aur Queues configure karein.
4. Dispatcher workflow ko run karke transactions enqueue karein, phir Performer execute karein.
